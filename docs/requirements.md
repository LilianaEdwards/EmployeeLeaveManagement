# Employee Leave Management System

## 1. Project Objective
Build a microservices-based application for submitting, reviewing, and tracking employee leave requests.

## 2. Problem Statement
Describe the manual process or business problem this system addresses.

## 3. Functional Requirements
- FR-01: Create and retrieve employee records.
- FR-02: Submit leave requests.
- FR-03: Validate leave dates and available balance.
- FR-04: Approve or reject pending requests.
- FR-05: Retrieve leave history and balance.
- FR-06: Publish leave events and record notifications.

## 4. Non-Functional Requirements
- Maintain clear service boundaries.
- Validate API input and return consistent errors.
- Log operational failures.
- Provide automated tests and reproducible setup instructions.
- Avoid duplicate notification records when events are redelivered.

## 5. Scope and Limitations
Document the supported leave types, working-day rules, authentication approach, and any excluded features.

## 6. Acceptance Criteria
List the end-to-end workflows that must work before the project is considered complete.
